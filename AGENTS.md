# Мнемозина: контекст для работы с репозиторием

Проект — локальная русскоязычная AI-визуальная новелла. Рабочая версия хранится в этом Git-репозитории; подробные этапы и границы будущих функций — в `docs/roadmap.md`. Текущая инфраструктурная спецификация — `docs/superpowers/specs/2026-09-24-global-app-shell-design.md`.

## Карта проекта

- `apps/web`: React, TypeScript, Vite, React Router, shadcn/ui (Mira, preset `b1D1mJdI`). FSD-слои находятся в `src/app`, `src/pages`, `src/features`, `src/shared`.
- `apps/api`: FastAPI, SQLModel, Alembic, SQLite, story engine и Ollama provider.
- `assets`: исходные материалы персонажей; `workflows/comfyui`: будущие workflow, но активной генерации изображений в приложении пока нет.
- `docs/roadmap.md`: статусы этапов; `docs/superpowers/specs` и `plans`: согласованные решения и планы.

## Действующие правила продукта

- FastAPI и SQLite владеют каноническим состоянием истории. LLM предлагает ход; проверка и запись выполняются сервером. Ошибка или непроверяемый ответ не изменяет состояние сессии.
- Игровая сессия восстанавливается по `/play/:sessionId`. `/studio/:sessionId` открывает ту же сессию в авторском тестовом режиме с инспектором.
- Глобальный сайдбар доступен во всём приложении. В игре он по умолчанию полностью скрыт; настройка иконок хранится только в `localStorage` браузера. Тема новеллы не должна менять системное меню.
- Каталог персонажей сейчас агрегирует данные историй только для чтения. Настройки показывают состояние провайдера, но не переключают серверную модель. Редактор персонажей, сюжетный граф, ComfyUI и backup пользовательских данных — будущие этапы.
- Используйте существующие компоненты shadcn/ui, не копируйте целиком `dashboard-01` и не создавайте замену базовым UI-примитивам.

## Запуск и проверка

См. `README.md` для клонирования, `.env` и Ollama. После установки зависимостей:

```powershell
npm run dev:api
npm run dev:web
npm run check
npm run test:e2e
```

`npm run check` выполняет lint, typecheck, frontend/backend tests и production build. E2E использует отдельную базу и fake Ollama. Не добавляйте в Git `.env`, SQLite, веса моделей и локальные артефакты проверок.
