# Проектирование AI Visual Novel v0.1

## Цель

Создать локальный однопользовательский движок визуальной новеллы. React отображает историю, FastAPI управляет объективным состоянием в SQLite, Ollama предлагает структурированное продолжение сюжета, а ComfyUI работает только как фоновый генератор изображений.

## Архитектура

Клиент обращается только к FastAPI. API хранит истории, совершеннолетних персонажей, сцены, ходы, задания генерации и ресурсы. Состояния Ollama и ComfyUI проверяются независимо, поэтому демонстрационный режим работает даже при отключённых сервисах.

Первый вертикальный срез поддерживает создание истории, демонстрационный ход, прогресс заданий и два режима изображений: кэшируемые спрайты и полноценные CG-сцены. Визуальный профиль и референсы образуют границу стабильной идентичности персонажа. LoRA и reference conditioning позднее подключаются через адаптер изображений.

## Состояние и сюжет

Источником истины служит SQLite. Ответ LLM считается предложением и не меняет канон напрямую. Ход содержит идентификатор запроса и ожидаемую версию состояния. Сервер проверяет изменения и применяет их атомарно; повторный идентификатор возвращает прежний ход.

## Изображения

При создании истории для каждого персонажа ставится задание листа, а после него — зависимые спрайты с базовыми эмоциями. CG использует тот же визуальный профиль, но создаёт всю сцену. Состояния заданий остаются техническими значениями `queued`, `running`, `succeeded`, `failed` и `cancelled`, а пользовательские подписи отображаются на русском.

## Интерфейс

Интерфейс полностью русскоязычный: экран создания истории, игровая сцена, повествование, реплики, варианты, свободное действие, статусы провайдеров и очередь изображений. ComfyUI не встраивается в игру.

## Ограничения

Возраст каждого персонажа — не менее 18 лет. Темы для взрослых являются метаданными. Каркас не создаёт графический сексуальный контент. Приложение работает локально и не содержит многопользовательской авторизации или публичного размещения.

## Проверка

Серверные тесты покрывают создание истории, возраст, версионирование и идемпотентность ходов, а также зависимости заданий. Клиентские тесты проверяют русский экран создания, игровую сцену и базовые компоненты shadcn/ui. Финальная проверка включает все тесты и production-сборку.
