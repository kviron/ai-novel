# Аканэ Куроха

Тестовая героиня для проверки спрайтов и будущей системы постоянной внешности персонажей.

Файл `akane-sprite-sheet-v1.png` содержит шесть состояний слева направо:

1. нейтральная;
2. радость;
3. грусть;
4. злость;
5. удивление;
6. поза с раскрытым веером.

Изображение имеет прозрачный фон и единый масштаб персонажа. Исходное описание внешности и правила сохранения идентичности находятся в `character-profile.json`.
