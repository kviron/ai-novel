# Мнемозина — локальная нейровизуальная новелла

Первый игровой срез приватной визуальной новеллы с локальной языковой моделью. Браузерный интерфейс показывает историю Аканэ, восстанавливает игровую сессию и принимает готовые варианты или свободные действия. FastAPI хранит каноническое состояние в SQLite, а Ollama предлагает следующий ход через строго проверяемую схему.

## Возможности текущего среза

- Русскоязычный интерфейс на React и TypeScript с глобальной навигацией, библиотекой и игровой сценой.
- Библиотека с обложкой и описанием истории: вкладка «Все новеллы» начинает новое прохождение, «Начатые» показывает одно активное автосохранение на новеллу и продолжает его из SQLite. Старые сессии не удаляются; авторские тестовые сессии в списке игрока не показываются.
- Общий каталог персонажей из доступных новелл (пока только просмотр), авторская студия для теста сессии и системные настройки.
- В новелле настройки открываются поверх сцены; вне новеллы — отдельной страницей. Сайдбар в игре скрыт по умолчанию, режим с иконками можно включить в настройках браузера.
- Встроенная история «Эхо неона», независимые игровые сессии и восстановление после перезапуска API.
- Версионированные, идемпотентные ходы с атомарной записью в SQLite.
- Кнопка «Отменить ход» возвращает до 10 последних ходов подряд. Новое действие после отката создаёт другую ветку: прежние ходы сохраняются в базе, но пока нет интерфейса карты веток и ручных слотов сохранения.
- Проверка доступности Ollama и списка установленных моделей через `/api/providers`.
- Единые русскоязычные ошибки API без утечки диагностических ответов модели.
- Основа интерфейса shadcn/ui и проектный skill для последующей работы агента.

## Первый запуск в Windows

Потребуются Git, Node.js 20 или новее, npm, [uv](https://docs.astral.sh/uv/) и установленная [Ollama](https://ollama.com/). Клонируйте репозиторий в удобный каталог:

```powershell
git clone https://github.com/kviron/ai-novel.git
cd ai-novel
```

Перед запуском загрузите модель, указанную в `.env.example`, или укажите в `.env` ID уже установленной модели из `ollama list`:

```powershell
ollama pull qwen3:14b-q4_K_M
```

Затем установите зависимости и создайте локальный файл настроек:

```powershell
npm run setup
Copy-Item .env.example .env
```

Откройте два терминала. В первом запустите API:

```powershell
npm run dev:api
```

Во втором запустите интерфейс:

```powershell
npm run dev:web
```

Приложение откроется по адресу [http://localhost:5173](http://localhost:5173). Выберите «Эхо неона» и нажмите «Начать историю». Ссылка `/play/<id>` восстанавливает прохождение после перезагрузки страницы. Документация API доступна по адресу [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs). База SQLite по умолчанию хранится в `apps/api/data/visual-novel.db`.

Git переносит код, документацию и пример настроек. Локальный `.env`, SQLite с вашими прохождениями и веса Ollama в репозиторий не входят. На другом ПК после клонирования нужно снова настроить `.env` и модель; пользовательские сессии автоматически не появятся. Для будущих помощников контекст проекта сохранён в `AGENTS.md`, а план развития — в `docs/roadmap.md`.

Текущие сохранения привязаны к локальной базе SQLite, а не к браузеру. Для переноса прохождений на другой компьютер потребуется отдельно скопировать файл базы, указанный в `DATABASE_PATH`; облачная синхронизация пока не реализована.

## Проверки

```powershell
npm run check
npm exec --prefix apps/web -- playwright install chromium
npm run test:e2e
```

`check` выполняет FSD и Python lint, проверку типов, unit/component tests и production build. E2E поднимает временный API, интерфейс и подставной Ollama; для проверки рядом с запущенным приложением задайте `E2E_WEB_PORT=5174`, `E2E_API_PORT=8001`, `E2E_FAKE_PORT=11436`. Он создаёт отдельную SQLite в `.runlogs/` и не требует запущенной Ollama или загруженной модели. Артефакты неудачного браузерного прогона сохраняются в `output/playwright/`.

## Подключение локальных моделей

Скопируйте `.env.example` в `.env` и при необходимости измените адрес Ollama, модель, размер контекста и таймаут. По умолчанию API обращается к Ollama по адресу `http://127.0.0.1:11434` и использует `qwen3:14b-q4_K_M` с контекстом 16 384 токена.

Если Ollama не запущена или нужная модель не загружена, игровое управление блокируется и предлагает повторить проверку. Запустите Ollama или выполните `ollama pull qwen3:14b-q4_K_M`, затем нажмите «Повторить проверку». API, сохранённые истории и восстановление сессий остаются доступны. Запрос хода в этих случаях возвращает русскоязычную ошибку `503` с кодом `provider_unavailable` или `model_unavailable`.

ComfyUI и генерация изображений относятся к следующему этапу и не являются обязательным или активным провайдером этого среза. Архитектура отделяет предложения языковой модели от канонического состояния игры, поэтому модель не меняет сохранённые данные напрямую.
