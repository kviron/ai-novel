# Сообщение игрока и выражение героя

Сообщение игрока остаётся свободным текстом. Парсер хода выделяет части в исходном порядке:

- без маркеров или между маркерами — свободное описание действия или состояния героя (`action`);
- `*действие*` — явно отмеченное действие (`explicit_action`);
- `«произнесённая речь»` или `"произнесённая речь"` — то, что слышат присутствующие персонажи;
- `(личная мысль)` — то, чего NPC не слышат сами по себе.

Незакрытый или пустой маркер остаётся обычным текстом. Сырой текст сохраняется в `Turn.action`; типы частей вычисляются детерминированно для промпта и предпросмотра. Версия интерпретации закреплена в `prompt_version` хода. Интерфейс не заменяет текст на разметку при отправке, поэтому черновик и старые действия читаются без миграции.

Герой берётся из неизменяемого снимка сессии. Доступные эмоции определяются по спрайтам закреплённой ревизии. Модель выбирает `visual_directive.protagonist_emotion` только из этого набора; сервер нормализует неизвестное значение в `neutral`. Выражение сохраняется вместе с подтверждённым ходом, поэтому перезагрузка и откат показывают то же состояние. Спрайт героя отображается независимо от состава NPC и только при включённой настройке игрока.

Модель получает мысли с явной пометкой приватности. Правило промпта запрещает NPC узнавать их напрямую. Семантическое соблюдение этого правила локальной LLM нельзя гарантировать одной JSON-схемой; это требует проверки на игровых сценариях. Отдельного спрайта смущения в текущем наборе героя нет: точное выражение станет доступным после добавления такого материала к ревизии персонажа.

Формат частей и `protagonist_emotion` пригодны как вход будущего генератора изображения сцены; текущая функция новых изображений не создаёт.
